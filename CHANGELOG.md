# История изменений

Значимые изменения PulseWatch и действия, необходимые при обновлении.

## 2026-11-09 — Валидация, авторизация и надёжность worker

### Исправлено

- Создание и PATCH мониторов используют общую проверку URL: разрешены только HTTP(S),
  некорректные порты и адреса возвращают `422`.
- `PATCH {"name": null}` и обнуление других обязательных полей возвращают `422`;
  `webhook_url: null` по-прежнему отключает webhook.
- SSRF-проверка учитывает IPv4-адрес внутри IPv4-mapped IPv6.
- Refresh-токены получают уникальный `jti` и заменяются атомарно в БД.
  Повторное использование старого токена возвращает `401`, в том числе при
  конкурентных запросах. Ошибка сохранения новой пары откатывает замену.
- Redis-блокировки имеют TTL 180 секунд, продлеваются каждые 60 секунд и
  освобождаются только владельцем. Потеря блокировки отменяет текущую проверку.
- `WORKER_ENABLED=false` предотвращает запуск worker и передаётся через Docker Compose.

### Добавлено

- Модель и репозиторий активных refresh-токенов; в БД сохраняются только SHA-256-хэши токенов.
- Миграция [`a4d17f92b6c8`](migrations/versions/a4d17f92b6c8_refresh_tokens.py).
- Регрессионные тесты для URL, PATCH, ротации токенов и отключения worker.
- Интеграционные проверки конкурентной ротации на PostgreSQL и блокировок на Redis.
- Обновлённый README: навигация, бейдж CI, схема архитектуры и инструкция обновления.

### Конфигурация и проверки

- Явно задан `asyncio_default_fixture_loop_scope = "function"`.
- В CI добавлен `REDIS_TEST_URL` для запуска интеграционных тестов.
- Проверено на Python 3.12: **102 теста прошли**, Ruff и mypy — без ошибок.
- Upgrade и downgrade новой миграции проверены на PostgreSQL.

### Обновление существующей установки

1. Примените `alembic upgrade head` перед запуском обновлённого API.
2. Убедитесь, что `alembic current` показывает `a4d17f92b6c8 (head)`.
3. Выполните повторный вход для получения новых refresh-токенов:
   токены, выданные до внедрения одноразовой ротации, больше не принимаются.

Команды для Docker Compose — в [инструкции обновления](README.md#обновление).
